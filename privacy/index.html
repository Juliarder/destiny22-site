1. Кто отвечает за данные

Оператор персональных данных — самозанятый Лодкин Юлиан Олегович, ИНН 667902350480. Контакт для обращений: destiny22.app@yandex.ru. Политика распространяется на Android-приложение Destiny 22, официальный сайт, серверную часть, функции Premium и обращения в поддержку.

2. Текущая стадия сервиса

Официальный сайт остаётся статическим: он не содержит формы регистрации или оплаты и сам не запрашивает данные профиля для расчётов. Android-приложение версии 1.1.0 предусматривает серверный аккаунт для покупки и восстановления Premium: пользователь подтверждает e-mail одноразовым кодом, после чего приложение работает с серверной сессией и серверным статусом доступа. Публичный приём реальных платежей до запуска обновления отключён; платёжный контур используется в тестовом режиме. Имя профиля и дата рождения, используемые для локальных расчётов, не передаются в серверный контур авторизации и покупки Premium.

3. Категории данных и цели

Для аккаунта и Premium могут обрабатываться e-mail, внутренний идентификатор пользователя, сведения о серверной сессии, идентификаторы и статусы заказов, выбранный продукт, сумма, срок доступа и сведения о выданном Premium. Одноразовые коды используются только для подтверждения e-mail. Для работы и безопасности сервиса могут обрабатываться IP-адрес, время запроса, сведения о клиенте и технические журналы. При обращении в поддержку обрабатываются контакт, текст обращения и добровольно сообщённые сведения. В приложении присутствует рекламный SDK VK Ads/myTarget, который может обрабатывать технические сведения об устройстве и рекламные идентификаторы в пределах, необходимых для показа и измерения рекламы. Не передавайте полные данные карт, CVC/CVV, пароли или одноразовые коды поддержке.

4. Аккаунт и Premium

Аккаунт используется только для покупки, подтверждения и восстановления Premium между локальными профилями пользователя. Бесплатные функции приложения не требуют обязательной регистрации. Купленный Premium хранится на сервере как право доступа, связанное с аккаунтом; временный доступ за рекламу хранится отдельно и не превращается в купленный Premium.

5. Минимизация данных

Destiny 22 обрабатывает только сведения, необходимые для конкретной заявленной цели. Специальные категории персональных данных и биометрия для работы сервиса не требуются. Имя локального профиля и дата рождения используются приложением для расчётов и не входят в серверный контур аккаунта и покупки Premium. Destiny 22 не продаёт персональные данные рекламодателям.

6. Основания обработки

В зависимости от конкретной операции основанием может быть заключение или исполнение договора по инициативе пользователя, исполнение обязанностей по закону либо отдельное согласие, когда оно требуется. Использование сайта само по себе не считается согласием на любые виды обработки. Согласие оформляется отдельно от иных документов в предусмотренных законом случаях; пользователь может его отозвать. При наличии другого законного основания обработка может продолжаться в необходимых пределах.

7. Платежи и передача данных

Платёжная инфраструктура Destiny 22 интегрирована с Robokassa; публичный приём реальных платежей включается отдельно после запуска обновления. Полные номера банковских карт, CVC/CVV и коды подтверждения Destiny 22 не получает и не хранит: такие данные обрабатываются платёжным провайдером. Для создания и проверки заказа передаются только необходимые сведения о заказе и платеже. Серверная часть и база данных размещаются у Amvera, одноразовые коды отправляются через почтовую инфраструктуру Яндекса, рекламные показы выполняются через VK Ads/myTarget, а официальный сайт размещается на GitHub Pages. Для каждого такого сервиса применяются его собственные правила обработки данных.

8. Сроки хранения

Данные аккаунта хранятся, пока аккаунт используется или пока есть законное основание для их хранения. Одноразовые коды и серверные сессии имеют ограниченный срок действия. Сведения об обращениях хранятся до решения вопроса и завершения связанных действий. Подтверждённые финансовые и фискальные сведения могут сохраняться после удаления аккаунта в объёме и на срок, требуемые законом и для подтверждения факта платежа. Данные, которые больше не нужны и не подлежат обязательному хранению, удаляются или обезличиваются.

9. Меры защиты

Сайт и серверные API доступны по HTTPS. Секреты платёжного сервиса, одноразовые коды и ключи доступа не размещаются в публичном приложении или на сайте. Серверные сессии проверяются на backend, а статус купленного Premium подтверждается сервером. Оператор применяет организационные и технические меры для защиты данных от неправомерного доступа, изменения, раскрытия, блокирования, копирования и иных неправомерных действий.

10. Права пользователя

Пользователь вправе получить информацию об обработке своих данных, потребовать уточнения, блокирования или удаления незаконно обрабатываемых либо ненужных данных, отозвать согласие и обжаловать действия оператора в Роскомнадзор или суд. Удаление может быть ограничено обязанностью хранить сведения по закону; оператор поясняет основания такого ограничения.

11. Как запросить уточнение или удаление

В версии приложения с аккаунтом пользователь может удалить серверный аккаунт непосредственно из настроек после явного подтверждения. При удалении активные сессии прекращаются, e-mail обезличивается, а серверный Premium отзывается. Подтверждённые финансовые записи сохраняются только в необходимом объёме. Также можно написать на destiny22.app@yandex.ru с темой «Персональные данные» для запроса информации, уточнения или удаления данных. Для защиты от доступа посторонних оператор может запросить минимально необходимые сведения для подтверждения принадлежности данных.

12. Обновление политики и контакт владельца

Политика обновляется при изменении фактических процессов обработки. Новые цели обработки не применяются автоматически на основании старого согласия.
